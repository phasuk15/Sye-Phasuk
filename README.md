# syephasuk.dev — Personal Portfolio Website

Welcome to the repository for my personal website, **[syephasuk.dev](https://syephasuk.dev)**.  
This site serves as my digital portfolio — showcasing my projects, experience, writing, and creative work at the intersection of software engineering, design, and interactive web development.

## ✨ Features

- Responsive, modern UI built with a design-first approach  
- Project showcase with case studies and technical breakdowns  
- Essays and writing section on technology and emerging topics  
- Smooth animations and interactive elements  
- Fully mobile-friendly and accessible  

---

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript / JavaScript
- **Styling:** Tailwind CSS
- **Animations:** AOS / custom CSS & React animations
- **Deployment:** Vercel
- **Content:** Markdown + Gray Matter
